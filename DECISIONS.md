# Решения (Этап 0)

Значения по умолчанию, выбранные при старте. Любое можно поменять — просто поправьте этот файл.

## T001 — продукт
- **Название:** TechStore (временное). Логотип — текстовый знак в шапке, без картинки.
- **Язык интерфейса:** русский (один язык в MVP; узбекский — позже).
- **Категории:** смартфоны, ноутбуки, наушники, телевизоры, аксессуары.
- **Доставка:** в MVP только тестовый заказ; в форме — выбор «доставка по Ташкенту / самовывоз» без реальной логистики.
- **Валюта:** UZS, целые числа.

## T002 — MVP
Входит и отложено — как в `PRD.md` §4. Админ-панели нет: товары загружаются сидом в базу.

## T004 — стек и хостинг
- Next.js 15 (App Router) + TypeScript, Tailwind CSS (единственный способ стилизации).
- Neon PostgreSQL + Drizzle ORM (Этап 2), Auth.js (Этап 6), Zod, Vitest/Playwright.
- Хостинг: Vercel.

## Запуск
```
npm install
npm run dev
```
Открыть http://localhost:3000
